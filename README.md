**웹 주소:** https://leanonmept.github.io/QT-meditation/

## 배포 방식

- GitHub Pages가 이 저장소의 **`gh-pages` 브랜치 루트**를 그대로 서빙합니다.
- 앱 파일은 `gh-pages` 브랜치의 `index.html` **하나뿐**입니다(외부 요청 없는 단일 HTML).
- 따라서 앱을 고칠 때는 `gh-pages` 브랜치의 `index.html`을 수정해야 사이트에 반영됩니다.
- Pickle의 GitHub 연결에는 Pages 설정 권한이 없어 Pages 설정 화면을 API로 바꿀 수 없습니다. 배포는 `gh-pages` 브랜치에 파일을 푸시하는 방식으로 합니다(푸시 후 보통 30~90초 뒤 반영).
